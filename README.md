## Production settings

The app needs these four settings. Each one is set on Vercel (Production) and in `.env.local` for local runs:

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY` (holds the Supabase publishable key)
- `OPENROUTER_API_KEY`
- `OPENROUTER_MODEL`
